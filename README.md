## 🚀 Getting Started

1. **Download:** Grab the latest `AccountManager.exe` from the [Releases](https://github.com/kontoist9-tech/Minecraft-Alts-Manager/releases/latest) page.
2. **Launch:** Run `AccountManager.exe` by double-clicking it.
3. **Add / Import Accounts:**
   - Click **`+ Add`** to add an account manually.
   - Click **`📦 Import`** to scan ZIP logs or token files.
   - Click **`📋 Paste`** to paste raw tokens or cookie headers directly.
4. **Play:**
   - Head over to the **`🎮 Game Launcher`** tab.
   - Select your profile and desired Minecraft version.
   - Click **`🚀 LAUNCH MINECRAFT`**!

## ⚙️ System Requirements

- **Operating System:** Windows 10 / Windows 11 (64-Bit recommended)
- **Java:** Java 8+ (Java 17/21 automatically detected from `.minecraft/runtime`)
- **Storage:** ~30 MB for the manager executable

---

## 🔒 Security & Privacy

- All account data is stored locally in your app data directory.
- Tokens and session cookies are validated directly with official Microsoft and Mojang authentication endpoints (`api.minecraftservices.com`).
