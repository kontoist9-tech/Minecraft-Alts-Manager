# 🎮 Minecraft Account Manager 2.0

Ein moderner, extrem schneller Minecraft Account Manager & Client Launcher mit Cloud-Synchronisation, Cookie-Importer und Multi-Version Support.

---

## 🚀 Features

- **🎮 Integrierter Game Launcher:** Starte jede installierte Minecraft-Version (Vanilla, Fabric, Forge, OptiFine) direkt mit deinem Profil.
- **⚡ High-Speed Cookie & Token Scanner:** Importiert und validiert ZIP-Dateien, Netscape-Cookies und Tokens in Millisekunden.
- **🔄 Auto-Checker:** Automatische Überprüfung von Skin, Name, UUID und Capes über die Mojang-API.
- **☁️ Cloud Sync:** Nahtlose Synchronisation im Hintergrund.
- **🛡️ Sicher & Standalone:** Keine Python-Installation nötig – alles in einer kompakten `.exe`.

## 📖 Anleitung

1. Lade dir die `AccountManager.exe` herunter.
2. Starte das Programm per Doppelklick.
3. Importiere deine Accounts / Cookies oder erstelle einen neuen.
4. Wähle im Tab **`🎮 Game Launcher`** deine gewünschte Minecraft-Version und klicke auf **`🚀 LAUNCH`**!
